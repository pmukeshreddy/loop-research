# Open-web validation implementation plan

> Execute the bounded tasks below with the subagent-driven-development skill for
> isolated provider work and independent review; integrate shared contracts here.

**Goal:** Generate self-contained X/Y datasets with private E and observed,
independent open-web validation, preserving legacy records.
**Architecture:** Separate public tasks, private generation evidence, observed
Codex sessions and open-web validation. Keep corpus validation as an explicit
legacy path; journal and export all attempts, traces and failure categories.
**Stack:** Existing Python/Pydantic/SQLite/Codex CLI; no paid SDK or provider.
**Spec:** [Open-web design](../../open-web-design.md).

## Constraints and review focus

$0 extra; pilot <=1.5M tokens, 50 calls, 15 web actions, concurrency 1. No filesystem
or private evidence in solver sessions. Test missing modes, forged self-reported
browsing, partial tool failures, unsupported citations and ambiguous alternatives.

## Stages

1. [x] Add research-mode contracts, self-contained generation prompts and isolated
   solver payload construction (`models.py`, `generation.py`, `pipeline.py`,
   `prompts.py`). Default absent mode to legacy. Regression tests before changes.
2. [x] Extend `providers.py` and `storage.py` with observed event traces and
   `ModelGateway.call_observed(...) -> (typed_response, observation)`. Preserve
   `call` compatibility. Observation includes web_events, visited_urls, tokens,
   searches, latency_seconds and failure information; cache and preserve failures.
   Test actual CLI flags, no local tools, strict filesystem policy, search/open
   activity parsing, budget stops and cached observations. Verify live capability
   with at most one bounded subscription probe, recorded separately.
3. [x] Implement `web_validation.py`: closed-book, fresh web solving, cited-page
   capture and independent grading, alternative search and grounded assessment,
   whole/partial shortcut probes. Fail closed on missing activity/access/budget.
   Add focused fake-provider tests, clearly labeled as scripted fixtures.
4. [x] Export open-web public X without corpus/evidence metadata; export private
   trace/verification records and accurate mode-specific metrics. Reject any
   attempt to export legacy candidates as open web. Add regression tests.
5. [x] Full pytest/Ruff, independent review, then a new bounded real pilot. Freeze
   implementation before running; preserve all failed attempts and previous runs.
   Update README and guides with X/Y/private E, commands, capability limits and
   observed results. No training or UI.
