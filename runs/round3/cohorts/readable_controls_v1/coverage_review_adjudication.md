# Common archived-evidence coverage review

This is a post-registration manual review adjudication, made before final control aggregation. It does not change predictions, the research output, automatic evaluator, source, tasks, runtime or metric definitions. Final listed-value support and exact citation membership remain assessed against each run's own retained cited evidence. Broader affiliation completeness is also checked against the same available archived B evidence across all seven B runs.

The first completed reviews reported five affiliation-coverage concerns for frozen-1 and zero for B0-1. A parent spot check found that both tables list only Brown for Kosterlitz, while frozen-1 retained an award-era Nobel biography mentioning a KIAS role. Different downloaded evidence therefore could not justify an absolute completeness advantage for an identical submitted value. Both original reviews and manual files are preserved; a separate common-evidence addendum will carry the final coverage judgment and its source-level support.

A second-pass check then found a genuine omission in **both reviews**, not merely a source-set difference: the Haldane Wikipedia text already retained in both runs contains his Perimeter Institute Distinguished Visiting Research Chair interval, 2013–2018, which spans the 2016 award. Both final affiliation cells list Princeton only. Each reviewer acknowledged the missed interval. Listed Princeton support, nationality support and the registered duplicate-overwrite metrics do not change merely because this additional coverage concern was found.

The shared index will preserve each candidate role's exact downloaded text, context, date evidence and confidence. A dated concurrent appointment is distinguished from an undated or unclosed continuation lead; neither is silently promoted into an established false value. Every B output is checked against that same index. If later completed B archives add another concrete candidate, it must receive the same cross-arm treatment before the final index and aggregate are frozen.

Final combined manual evidence will retain the original review/metric receipts and explicitly cite the common-evidence addendum for the resulting affiliation-coverage count. Counts corrected after this second pass must be described as corrections. This is a broader evidence check for the already registered semantic/coverage review, not a new directional prediction or a statistical result. The complete original outputs and archive inventories remain untouched.
