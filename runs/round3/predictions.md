## Fixed measurement definitions

**M1/M2.** Count completed individual search requests, including children of a batch and cache/shared requests. M1 is the number and fraction without a matching exact-query discovery event after search completion and by the next depth-0 REPL block end. An honest empty record satisfies timing. A missing next boundary is N/A. M2 counts each empty exact-query discovery event that has a later nonempty record for that same query; it does not label an uncorrected empty record wrong. The original exact query is retained, without case/whitespace normalization. M1 is descriptive here, not a directional prediction.

**R1.** R1_failed_primary_urls counts distinct failed URLs that the executed trajectory identifies as primary/official evidence for the task. R1_official_alternate_recoveries counts distinct such failed URLs for which a later successful different URL supplies the needed evidence from the same authoritative publisher or its official publication host, including a PDF, with the alternate selected from an actual search result. A mere successful unrelated fetch is not a recovery. Cite failure, search result, subsequent fetch, and use. Count each failed URL once. Report raw numerator and denominator, and the recovery count conditionally as N/A if there is no failed primary URL. General failed-URL repeats use all failed URLs, not just the official subset. Repeated requests admitted before the first failure are excluded; a zero denominator is N/A, never zero. This predicts agent behavior, not any downloader fallback: failed downloads stay failed with recorded reasons.

**R2.** R2_retained_download_reuse_blocks counts distinct executed depth-0 code blocks that reuse a previously completed successful download from an earlier block, by reading retained text/structured evidence or passing it to a sub-call, without another fetch of that URL in the reusing block. Count a block once even when several documents are reused. Cite both the earlier download assignment and later code/output. Same-block first extraction and mere printing a saved length do not count. This is a conservative direct evidence-reuse measure; a small task or a complete single-block batch can leave little opportunity. Search-result reuse is separately described using repeated exact queries and trace-backed retained-hit examples; no directional claim is made for that descriptive proxy.

**S1.** Use the existing `answer-ready-v2` scoring contract. Binary 1 requires executed code before the first root submission setting `answer["ready"] = True` to verify nonempty values, source lists and quotes for every required cell in the actual nonempty submitted candidate rows, and exact quote membership in retained original text for every cited URL. Identify the first depth-0 code.end with answer_ready=true and cite code/output proving the checks precede its readiness assignment. A failed guard followed by repair and a complete successful guard can score 1. Partial checks, checks of a different earlier row version, checks after submission, and assurances score 0. No submission is N/A. The former first-cohort `records.add` prediction used an unavailable API; that old prediction remains N/A and is not retroactively rescued by this prospective contract.

**S2.** Report a binary gap-exposed flag and the count of successful unique supplementary URLs explicitly directed at a missing required field after that gap is visible in executed code/output. Cite the gap, fetch and field. If no gap is exposed, raw count is 0 and the conditional metric is N/A. Increased supplementation is predicted only given exposure; initial source completeness can change exposure.

**S3/S4.** S3 counts REPL blocks terminated by a quotation-validation exception. Caught/printed quote failures are separately counted as individual printed records, retaining repeated observations. Nonexception detection/repair is not an exception block. S4 counts final required cells whose quote is missing/empty or fails exact membership in any cited URL's retained original text; missing sources/text also violate it. All error categories remain reported independently. Early validation can reveal more provisional problems even if final quality improves.

**G1/G2/G3.** G1 counts distinct `(row identity, required field)` pairs for which code, a sub-call, or root reasoning identifies a concrete potentially omitted value or dated conflict, not a generic instruction to check accuracy. G2 counts those pairs still unresolved at submission: no supported inclusion and no evidence-based dated exclusion addressing the finding. Merely repeating an initial source, an inconclusive search, or a narrowed field definition is not resolution. G3 counts distinct exposed pairs explicitly dismissed solely because an awarding body's/preferred publication omitted the value, or because the agent substitutes a narrower field definition without task authorization. Count each pair once; cite the exposed finding and its final treatment. Report all three raw counts and G2/G3 conditional counts as N/A when G1=0. Potential findings are distinguished from independently established factual errors: a model's audit assertion alone does not prove a true omission. The prediction concerns how findings are reconciled, not maximizing the number of claimed affiliations.

**Q1 and semantics.** Identity difference is against the saved Round 2 Physics `(laureate, year)` identities, with any explicit spelling aliases documented from evidence and raw differences retained. Review every final cell's semantic support separately. Automated zero issues and quote membership are necessary evidence, not proof of semantic completeness. Report concrete semantic support/completeness concerns and their count without rewriting the raw outputs.
