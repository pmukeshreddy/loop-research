## Fixed measurement definitions

**S1: answer-ready-v2.** Binary 1 requires executed code before the first root submission setting `answer["ready"] = True` to verify nonempty values, source lists and quotes for every required cell in the actual nonempty submitted rows, and exact quote membership in retained original text for **every** cited URL. Locate the first depth-0 `REPL code.end` with `answer_ready=true`; checks must precede that readiness assignment and cover the submitted version. A failed guard followed by repair and a complete successful guard may score 1. Partial guards, guards of an earlier row version, checks after submission and assurances score 0. No root submission is N/A with a reason. This is observed behavior, not causal proof. The old first-cohort prediction naming unavailable `records.add` remains N/A; it is not retroactively rescued.

**S2.** Report the binary missing-required-field gap exposure flag and the number of successful unique supplementary URLs explicitly directed at that gap after it becomes visible in executed code/output. Cite gap, field and fetch. If no gap is exposed, raw count is 0 and the conditional metric is N/A. More follow-up retrieval is predicted only given exposure; initial source completeness can change exposure. Also report whether the fetched evidence actually resolves the cited gap; fetch success alone is not support.

**S3/S4/V1.** S3 counts root REPL blocks terminated by a quotation-validation exception. Separately count individual caught/printed quote-failure records, including repeated observations. Nonexception detection is not an exception block. S4 counts final required cells with missing/empty quote or sources, absent retained text for any cited URL, or, for any cited URL, a quote occurring in none of that URL's retained original texts; count a violating cell once. No whitespace/case normalization. V1 counts S3 blocks with a bare/uninformative exception and no identifying failure diagnostic in that executed block. A diagnostic is identifying only if it names the entity, required field, source URL and failed quote condition; merely printing the whole table is insufficient. Report raw V1 and its conditional count, which is N/A when S3=0. This measures diagnostic adequacy only for terminated quote-guard blocks, not every possible validation error.

**D0–D3.** Use the task's entity keys, with explicitly evidenced aliases only. D0 counts distinct `(entity identity, required field)` groups for which the executed trajectory receives multiple extracted candidates in one batch or explicitly assembled candidate set before updating the accumulated table. Ordinary sequential verification of a single existing record is not a duplicate group. Detect groups from retained extraction results and executed merge code even if the agent did not notice them. Count each group once per run. D1 counts exposed groups whose complementary/conflicting evidence was checked and reconciled before the group's first mutation of the accumulated cells; selecting one candidate only qualifies when evidence shows it covers all supported components or rules the others out. A duplicate count alone is not reconciliation. D2 counts exposed groups where sequential replacement drops an already supported component despite that evidence being available; source-list changes with an unchanged complete value are not a value loss. A later repair does not erase this earlier destructive overwrite. D3 counts those D2 groups still missing a supported dropped component at final submission. Cite candidate records, executed assignment order, values and final treatment. Report all raw counts plus D1/D2/D3 conditional counts as N/A when D0=0. Report the field-level evidence and uncertainty; a model audit allegation alone cannot establish a dropped supported fact. If evidence cannot determine a count, use N/A with the reason, never a guessed zero.

**F1.** Count individual actual research extraction or verification subcalls whose source-evidence payload includes an exact recorded failed-fetch return, even if accompanying instructions say to ignore failures. Bind the exact failed return to its request and the subcall input. Exclude calls explicitly tasked with diagnosing a failure, and exclude refinement calls. A purely instructional mention of a sentinel is excluded. Count a subcall once even if several failed responses occur. Report raw count, failed-fetch exposure, and a conditional count that is N/A when there are no failed fetches. This is not a count of failed downloads: all failed downloads still count and retain their reasons. Mixed-batch examples must identify both the successful and failed requests; no recovery success is inferred from silence.

**R2.** Count distinct executed depth-0 blocks that reuse a successful download completed in an earlier block, by reading retained text or derived structured evidence or passing it to a subcall, without another fetch of that URL in the reusing block. Count a block once even if it reuses several documents. Cite the earlier download/assignment and later code/output. Same-block first extraction and mere printing a saved length do not count. This measures saved evidence use; a complete single-block solution can leave little opportunity. Reuse of saved search hits is separately described with cited examples and repeated exact-query counts, without claiming that those counts prove reuse.

**Failed-URL repeats.** Count admitted fetch requests for an exact product-normalized URL after its first failed fetch completion. Concurrent duplicate admissions before that failure are excluded. Report total repeats, distinct failed URLs and repeats per distinct failed URL; zero denominator is N/A. Cache/shared/cancelled/pending requests remain separately reported. A failed URL need not eventually succeed if other verified evidence resolves the claim.

**M1/M2 and search repeats.** Count individual completed successful searches, including batch children/cache/shared requests. M1 is the number/fraction without a matching exact-query discovery after completion and by the next depth-0 block end; an honest empty discovery satisfies timing. Missing later boundary is N/A. M2 counts each empty exact-query discovery that is later followed by a nonempty record for the same query; an uncorrected empty is not classified as wrong. Search repeats are requests after the first successful completion of the exact original query, without case/whitespace normalization; concurrent earlier duplicates are excluded. These are descriptive in this cohort because the discovery procedure did not change.

**Q1 and semantics.** Compare Physics `(laureate, year)` identities with saved Round 2 using the unchanged normalization; retain raw differences and cite every alias correction. Review every final cell's semantic support separately, distinguishing unsupported values, concrete unresolved findings and broader coverage concerns. Mechanical zeros and substring membership alone are not proof of semantic completeness. Report semantic counts and concrete concerns without rewriting raw outputs.
