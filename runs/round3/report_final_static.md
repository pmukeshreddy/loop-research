## 1. Full readable pages

**Root cause.** The former `ResearchTools.fetch → CodexBackend.complete(purpose="fetch", web=True)` returned the sub-model's final message. The native web open was a different boundary: Round 2's 375 observed opens exposed line-count metadata and no full-body field. A 122-line open yielded a 270-character refusal; a focused retry yielded 509 characters. Meanwhile complete task instructions, code, printed outputs and root history accumulated. Hence A's fetched 12,187 characters stayed below its largest 79,147-character root, and frozen B's 29,020 stayed below 122,054. These are **old-fetch-path** measurements. [Gate evidence](fetch_gate_evidence.json), [Round 2 source trace](../research-65cc14c4722a4caf9c67f56e2883a0ca/289901ce021c28d56fdac993/codex_calls.jsonl:47).

**Diff and generalization.** After the recorded stop-and-ask and user approval, commit `313603d1abf58a64f3fa8f22585a477fc776a574` replaced model-rendered fetch returns with direct retrieval. Any agent-selected public HTTP(S) URL is eligible, including search hits; there is no hand-picked site list. Checked DNS addresses and every redirect must be public, connections pin the checked IP and HTTPS authenticates the original hostname. Codex web search still discovers sources. Static HTML/text extraction retains full readable content; Poppler extracts every PDF page. The entire returned text enters REPL variables for code/subcalls. Focus is intent metadata and cannot shorten a page. Exact response bytes, redirect hops, extracted text and hashes remain on disk. The cache verifies those receipts. Failed downloads record their reasons, with no model fallback or automatic re-download. No padding, artificial content duplication, count-driven fetching or new research-root truncation was introduced. [Implementation](../../src/loop_research/page_fetch.py), [RPC/cache path](../../src/loop_research/repl_tools.py), [fix and tests](fetch_fix.md).

Tests cover full multi-section HTML and multi-page PDFs, hidden/optional tags, CRLF preservation, redirects, public-address validation, cancellation/deadlines, cache integrity and actual isolated-worker transport. Final targeted fetch/audit checks: **70 passed**; the final integrated suite below covers all fixes. Static extraction cannot render JavaScript or OCR an image-only page; such failures remain visible. Raw bytes, readable characters and returned characters are reported separately. Full text in a variable alone does not establish the required size/overlap/quality conjunction.

[Completion visibility](../round2/explicit_refine_status_analysis.md), [missed retrievals](../round2/A.refine_analysis.md:488).

Existing root boundaries apply ready work without waiting, then supply that status and full entries. Retrieval unions complete committed current-run entries with the unchanged relevance results, deduplicating identities without dropping metadata or fabricating positive scores. The agent still chooses whether, when and why to request refinement. No automatic mid-task trigger, forced edit, sleeping or polling was introduced. Provenance and lifecycle govern this behavior, independently of task or site. [Status implementation](../../src/loop_research/refine.py), [retrieval/feedback](../../src/loop_research/session.py), [fix evidence](same_run_fix.md).
